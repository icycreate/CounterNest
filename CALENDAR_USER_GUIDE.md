# Operations Calendar user guide — RC9

Open Operations → Calendar. Computers and tablets start in Week; phones start in Agenda. Choose Month, Week, Day or Agenda. Today returns to the business's current date. Previous/Next move the active period. On touch devices, swipe horizontally on blank calendar space; the same actions remain available as buttons.

Search titles, references and customers using the shared search box. Filter by event type, status or assigned staff. Date Range accepts up to 60 days; Agenda normally covers 14 days. Filters remain while navigating in this signed-in business session. More than 200 matches show Load more; warnings cover loaded records, so load remaining pages before assessing the whole range.

Event cards show the source reference, type, title, quantity, status and staff where available. Date only means the original record has no clock time. A cake appears once, using pickup when present, otherwise its deadline. Today is a separate short daily summary (up to 20 records); use Day for the complete list. The Unscheduled panel lists up to 25 accepted pre-orders without pickup times and shows the total count.

Tap an event to inspect its original record and ingredient/order lines. Open source workspace takes you to that original module with the selected reference above it. Back closes an event detail first; Back from the original workspace returns to Calendar. An edited schedule prompts before leaving. Existing global navigation and OS Back rules are preserved.

With permission, choose Reschedule. Production supports date, optional start/expected finish and assigned staff. A finish requires a start and must be later. A date-only batch has no assumed duration. Orders support pickup and cake deadline; deliveries support the source PO's expected date. Enter a reason of 5–500 characters and save. The business timezone is displayed. An invalid local time is rejected. If another person changed the schedule, reopen the record and review the new values before trying again. Every date/assignment change is audited with old/new values, actor and timestamp; other module edits are audited too.

New Pre-Order, New Custom Cake, Schedule Production and Create Purchase Order open original module forms. Their original permissions and approval rules apply. Drafts or approval requests appear only after becoming an eligible original source record with a schedule. Calendar refreshes on return, manually with Refresh, and every 30 seconds while visible.

Warnings identify timed production overlaps, linked pickup before expected finish, reserved-ingredient shortages, related delivery later than production, overdue cake deadlines and overdue deliveries. Use View Conflict or View Shortage to inspect the source and reschedule as appropriate. These are planning snapshots: they do not reserve stock, guarantee delivery allocation, or block production. Untimed or completed batches do not create invented overlap warnings.

Cashiers see pickup/cake events; production staff see production; inventory staff see deliveries. Managers and administrators have broader views subject to existing operation permissions. Accounting has no Calendar access. Creating orders/production follows the existing administrator-only module rules; production rescheduling and purchasing follow existing manage/create permissions. Other businesses' records are never returned.

Calendar controls follow English, Español, 繁體中文 and 简体中文. Business-entered titles remain unchanged. Appearance follows Light, Dark or System and your selected accent. The browser app supplies the same Calendar to mobile/PWA; physical installed-device acceptance is listed in the UAT checklist.
