# Catalogue appearance

Catalogue → Catalogue Settings → Appearance. Choose Theme Color, Gradient or Custom Header Image. Upload/replace opens the existing crop editor. Save crop uploads the cropped header and original, then use Save Appearance to publish. Edit / crop reopens the stored original. Focal horizontal/vertical sliders reposition the decorative image. Overlay and blur update the preview. Remove image returns that region to its theme mode; Reset to default restores both regions and all position/strength values, then Save Appearance publishes.

Background Style supports Theme Background or a custom uploaded/cropped image. Background strength is bounded to protect readable controls. Header opacity is at most 10%, background opacity at most 5%; panels and controls retain theme surfaces. Assets are public decorative branding in the workspace's catalogue-branding bucket. Only the active administrator can change them; storage objects and RPC paths are validated. Removed/replaced assets remain in storage for older references and workspace backups.

The catalogue retains the business accent and customer Light / Dark / System choice; new devices default to Light. Decorative photos never set the theme palette. The responsive header presents full contained logo, centered business name, Language, Appearance, Install Catalogue App, Fullscreen and QR. Enabled Contact Business methods and unified filters remain available below. Business/product/variant/custom labels stay as entered.

Use landscape or original-proportion crops for headers and inspect the focal point at phone and tablet widths. Custom business logos are contained; CounterNest's default full mark is used in medium/large areas, dedicated icon in compact headers/browser favicon/PWA icons.
