# Catalogue editors — business user guide

Open Settings → Catalogue Settings as an administrator. Choose Home Page Editor, Categories Editor or About Us Editor. Each section has its own Save Changes button and does not save the other sections.

## Home Page

Choose the default content language, then the language you want to edit. Enter the heading, welcome, short description, promotion and button text. Choose an existing button destination. Turn banner, links or products on/off as needed.

Upload up to eight JPEG/PNG/WebP images, crop each, and save the crop. Use the arrows to reorder, Replace image to change one, or Remove image to unpublish it. Add optional captions per language. Select desktop and mobile image fit. Preview, then Save Changes. Originals are retained separately from the display crop.

## Categories

Choose an existing category or Add category. The category name is the canonical POS name; Category display name and description can have independent translations. Add one optional cover image, reorder categories with the arrows and choose Show category. Hiding does not delete the category/product or remove it from internal POS. Existing bundles keep their definitions, so review those separately. Save Changes publishes the category edits together.

## About Us

This edits the existing customer About Us page and its Picture 3. Change the business heading, introduction, story, optional highlight and image alternative text. Upload/crop or remove the About image, preview and save. These controls do not modify product photos or Home banners.

## Languages, defaults and drafts

The system language changes control labels immediately. Edit content language changes which authored translation you are editing. Empty translated fields fall back to the default content; CounterNest does not invent translations. Changing the public language never rewrites product, customer or business names.

Cancel discards the current editor's unsaved edits after confirmation. Restore defaults changes the draft only; review and save to publish. Home/category defaults clear that section's authored presentation/media. About defaults hide/clear the About section. Switching editor tabs keeps drafts; leaving the page with unsaved edits asks for confirmation. A concurrent-edit error requires reopening/reloading the editor before retrying.

## Order notifications

Authorized staff use Order notifications to open a request, mark it read or mark all read. View later dismisses a popup without deleting the request. Contact uses the customer's preferred method; it does not silently send an external message or accept an order. Accept opens confirmation; Decline requires a reason. Alerts wait while a payment/dialog is active.

Configure sound and device push under Settings → Notifications. Device permission is requested only after you choose Enable notifications on this device. Background delivery requires completed backend setup; custom sounds play only while the app is active and audio is allowed.
