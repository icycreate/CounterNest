# RC5 known issues and UAT limits

- No Vercel/Supabase deployment or real business mutation was performed. Real Auth/password verification, allfive Edge gateways, private Storage upload/download, Realtime and provider/physical-device behavior require staged UAT.
- Backup ZIPs are uncompressed and bounded to48MB. Test realistic archive sizes against deployed Edge memory/response/time limits; larger estates need platform database/Storage recovery. External files, Auth accounts/platform secrets/sessions, staff authorization grants and user preferences are excluded. Staff accounts must be invited again; historical authentication references map to the restoring owner. Keep the original archive for historical actor context.
- Permanent deletion is operator-disabled by default. Existing owner backfill chooses the oldest active administrator; review it before launch. Cancel within30 days. Purge requires operator enablement, expiry, fresh backup/password/name/confirmations; it does not run automatically. Cleanup failures need operator follow-up.
- No-approval and optional receiving verification are compatibility defaults; configure threshold/always approval and required verification before enforcing the new workflow. Legacy direct receiving is blocked when verification is required.
- Purchase quantities are base-unit values rounded to configured supplier packs. Enter equivalent pack quantities correctly. Forecasts and supplier reliability/quality are manual planning inputs. Do not count accepted orders again as forecast. Physical ledger balance projections still require reviewing expiry/recall alerts and recording disposal/waste; FEFO consumption refuses invalid lots.
- Barcode input supports hardware scanners acting as a keyboard and manual entry. Native camera scanning is not part of the new package-verification dialog. No supplier messages are sent automatically.
- CSV/XLSX imports support the first worksheet, up to500 rows, 100 columns and8MB. Formula cells, macros/nonstandard or unsafe archives and invalid rows are refused; export formulas as values. New master records are created, existing ones are not overwritten. Opening Inventory explicitly adjusts a named ingredient balance. Browser deflate support is required for XLSX; CSV is the fallback.
- New permission customization covers operational actions. Legacy customer/payment/financial actions retain base-role guards. Accounting provides a read-only overview; Manager handles operational purchasing/forecast/cost actions without blanket financial administration.
- Native-speaker review of allfour languages, screen-reader/mobile-device review and physical print/PWA install/reopen remain target-device checks. The existing main app/language bundle is large; Vite emits a chunk-size advisory.
- Prior receipt/image/PWA limits continue: missing historical originals cannot be reconstructed; tenant icon selection/reinstallation is platform-dependent; catalogue data needs a connection.
