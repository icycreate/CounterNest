# RC12 known issues and verification limits

This is a locally validated release candidate. No GitHub push, Vercel deployment or production Supabase migration was performed. Real Supabase auth/RLS/storage HTTP, cloud concurrency, Edge functions, external notification delivery and physical installed PWA acceptance require the staging checklist.

Inventory retains 0.001 base-unit quantity and 0.000001 normalized cost precision. Cooking units are US customary; use an explicitly named custom unit for a 250 ml cup. Source snapshots retain entered values, but high-factor purchase costs may round in base ledgers. Choose an appropriate base unit and reconcile material valuation differences.

Existing inaccessible remote originals may fail the crop fetch due to CORS; viewing/replacement remains available. Removed images remain in storage for historical documents/backups; there is no automatic orphan-file purge. Variant photos join the shared gallery rather than acting as a variant-specific customer slideshow.

The frontend remains a large established application; Vite may report the existing large-chunk warning. No new runtime package was introduced. Automated token contrast checks cover representative accents and states, while visual acceptance of every screen/custom image still requires human review.

Screenshots are produced from the actual components using isolated sample-data fixtures. They demonstrate local UI, not live cloud operation, financial transactions or business acceptance. See SCREENSHOT_EVIDENCE.md for capture scope.
