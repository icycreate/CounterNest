# CounterNest RC15 release notes

Customer Catalogue now uses a mobile-first food storefront with a related desktop sidebar experience. Admin retains its operational navigation and permissions with compact tables, summary cards and reordered dashboard information. Business accents, enabled contacts, language, logo fallback and customer theme preference remain configurable.

The supplied mockup is adapted to actual available data: real product images and prices are used; nonexistent popularity metrics, growth percentages, sign-in flows and payment processing are not fabricated. Account groups the existing local preferences, favorites, order links and installation help.

No database migration is required. No production data was accessed or changed. This is a local release candidate ready for GitHub/Vercel review; it has not been deployed. See BUILD_VALIDATION_REPORT.md and KNOWN_ISSUES.md for validation boundaries.
