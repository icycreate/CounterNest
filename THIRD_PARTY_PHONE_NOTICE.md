# Local phone metadata attribution

This release reuses the locally available libphonenumber bundle from Microsoft Office SolutionPackages OfflineFiles (`libphonenumber-bundle-3d20536298ff0024.js`). Only the application-specific webpack chunk wrapper was removed; the library and metadata remain bundled locally. No package was downloaded. The library exposes Google libphonenumber PhoneNumberUtil and AsYouTypeFormatter and Closure runtime components. Google libphonenumber is distributed under Apache License 2.0. Preserve upstream attribution and applicable license notices when redistributing. The local bundle did not include a version manifest; its numbering metadata may predate recent numbering-plan changes. No online metadata freshness claim is made.
`src/vendor/LICENSE-APACHE-2.0.txt` contains the Apache 2.0 license text. Attribution: Google libphonenumber authors and contributors; Google Closure Library/runtime authors and contributors. The application-specific webpack registration was removed locally on 2026-10-23.
