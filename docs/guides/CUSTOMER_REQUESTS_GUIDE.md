# Catalogue, pre-orders and register opening

Admin selects customer contact methods in Settings and saves the HTTPS public origin in Display Settings. Use Copy Catalogue Link, Show/Save QR or Print QR. Protected links require their display token. After a URL/token change, reprint physical QR signs/PDFs. Customer phones need only a browser.

Customers open product detail, choose variant/quantity, add to pre-order and continue shopping. Customer information asks for name, one enabled preferred contact method, contact details and optional notes; initial pickup is not required. Review and submit once. An uncertain response uses Retry Same Request to recover the same number. The private status link can be kept on that device. Submission takes no payment and reserves no stock.

Staff open Catalogue Requests. Use Accept Order directly, confirm items/quantities and the refreshed server quote, optionally enter pickup/deadline, customer instructions/private staff note and a deposit actually received. Cash requires an open register. Accept creates one linked order; it does not produce or deduct stock. Decline Order requires a reason. No manual Under Review/Contacted/Awaiting Confirmation sequence is required. Historical states remain readable.

After acceptance, Print Receipt / Save as PDF opens the customer confirmation. Staff notes never appear. Pickup is printed only when confirmed. Unpaid totals use current tax settings until payment; paid reprints use recorded sale totals. Use the linked order for final payment and planning. The shared kitchen queue and production overview include accepted items without re-entry. Approved ingredient production continues through the normal planner/FEFO workflow.

Use only Contact via the customer's selected method. Admin override requires another destination and an audited reason. Templates prepare editable messages for accepted order, more information, deposit, confirmed pickup, ready or decline. No message is automatically sent.

The customer catalogue supports manual product detail, filtering, fullscreen and four languages. Automatic slides and timed rotation are removed. Product descriptions remain as entered. New photo uploads open the crop editor before saving; original download is available. PDF catalogue defaults to portrait product cards with authoritative current prices, business/default branding and QR.

Login only authenticates. Admin then opens Daily Cash, selects station and enters opening cash (zero allowed). Opening actor/time/amount/station are audited. Cashiers do not change opening cash. The register remains shared per business/day; independent per-station balances are not provided.
