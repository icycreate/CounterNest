# CounterNest POS v1.4.0 - Phase 30.2

- Standardized application content text to black for higher legibility; white text is retained only where required for contrast on dark action buttons and membership cards.
- Changed the desktop navigation background to a light neutral surface so its black labels remain readable.
- Added a device-persistent System Language selector under Settings with English and Spanish navigation/page-title support and localized page dates.
- Added Android installation guidance and an in-app Android install action using the existing PWA prompt.
- Restored optional Capacitor Android dependencies and build commands for Android Studio/debug APK installation.

No Supabase migration is required.
