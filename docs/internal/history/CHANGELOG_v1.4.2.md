# CounterNest POS v1.4.2

- Added customer search by customer/loyalty Card ID, customer name, or phone number.
- Phone matching ignores spaces, hyphens, parentheses, and other formatting.
- Card scanners operating as keyboard input can scan directly into the search field and submit with Enter.
- A single match can be selected and opened directly in New Sale.
- Customer records display their issued Card IDs for verification.

No new Supabase migration is required beyond migration 27 from v1.4.1.
