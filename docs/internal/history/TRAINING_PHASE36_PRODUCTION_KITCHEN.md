# Phase 36 training — Production Kitchen

1. Sign in and open Preparation / Kitchen, or the dedicated /?preparation=1 screen on a staff tablet.
2. Work oldest received orders first; read variant/options, quantities, notes and wait time. Start preparing, mark ready and mark collected after payment. Changing status never deducts inventory.
3. Review scheduled pickup/cake jobs and production instructions separately from walk-in orders. Complete approved production batches through the existing Production module. Recipe scale converts variant sellable units to base recipe units; use the approved batch planned quantities.
4. Independent variant output transfers into its lot ledger automatically on batch completion. Completing the same job again is blocked.
5. Check Forecast / Shortages with management for usable ingredient lots and affected jobs. Receive missing supplies through existing FEFO/lot workflows; do not override or manually deduct stock merely to clear an alert.

Training evidence: record staff, date, device, observed outcomes and manager sign-off in the release UAT evidence.
